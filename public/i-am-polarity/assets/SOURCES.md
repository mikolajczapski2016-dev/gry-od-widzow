# Character models

Quaternius, Ultimate Modular Men Pack (2022), CC0 1.0 Universal.
- Casual_2 → casual.glb
- Casual_Hoodie → hoodie.glb
- Worker → worker.glb

Author's pack page: https://quaternius.com/packs/ultimatemodularcharacters.html
Official download: https://drive.google.com/drive/folders/1USAAquX2JJWuA2m6zol0KUkFe3UkZ8zX
License: https://creativecommons.org/publicdomain/zero/1.0/

Original self-contained glTF files converted losslessly to binary GLB.
Meshes, materials, skeletons and animations are preserved. Runtime models are
scaled to the same 1.85 m height and use the included skeletal animation clips.

Three.js and its loaders: MIT, r160. See ../vendor/LICENSE-three.txt.
The original environment, props, gloves and magnetic effects are generated by
this project's code. The game is not affiliated with New Folder Games.
